## 📝 Overview
This repository contains the completed **Assignment #2** for the Web Technologies course. The primary goal of this assignment is to master modern 2D and 1D CSS layout techniques using **Flexbox** and **CSS Grid** to build responsive, flexible, and efficient web pages without using legacy floats or external frameworks[cite: 1].

---

## 🛠 Project Structure & Navigation
The project is split into separate HTML pages linked seamlessly via a common Navigation Bar (Navbar) across the site[cite: 1]:

* **`index.html` — Part 1: Flexbox**
  * **Task 0 (Navigation Bar):** A header flex container with a logo on the left and navigation links centered vertically on the right[cite: 1].
  * **Task 1 (Card Row):** Equal-height project/skill cards arranged in a row using Flexbox with smooth hover effects (`transform`, `box-shadow`)[cite: 1].

* **`part2.html` — Part 2: Grid System**
  * **Task 2 (Page Layout):** A full page structure (Header, Sidebar, Main Content, Footer) built using `grid-template-areas`[cite: 1].
  * **Task 3 (Image Gallery):** A 3x3 responsive grid gallery with equal-width columns, consistent gaps, and an image overlay caption on hover[cite: 1].

* **`part3.html` — Part 3: Combining Flexbox & Grid**
  * **Task 4 (Portfolio Page):** A complete portfolio layout combining CSS Grid for overall page areas and project grid layouts, and Flexbox for navbar links and internal project card element alignments[cite: 1].
